# ZXing.Net 0.16.10

`zxing.dll` is the `netstandard2.0` build from the ZXing.Net NuGet package
(https://www.nuget.org/packages/ZXing.Net/0.16.10), unmodified.

Licensed under the Apache License 2.0. Copyright the ZXing.Net authors.
https://github.com/micjahn/ZXing.Net/blob/master/COPYING

Used by the arcade launcher to encode an external entry's `playUrl` into a QR code at
runtime, so a catalog publish alone is enough to show a scannable code on the cabinet.
